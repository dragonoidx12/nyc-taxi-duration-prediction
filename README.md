# NYC Taxi Trip Duration Prediction

New York taxi trip duration prediction project.

## Models
- Baseline Regression
- Random Forest
- HistGradientBoosting
- HistGradientBoosting + Feature Engineering

## Best Model
HistGradientBoosting + Feature Engineering

Validation RMSLE: 0.411019

## Features
- Geographic distance calculations
- Pickup date and time
- Rush hour detection
- Cyclical time features
- Feature Engineering

## Deployment
Streamlit Community Cloud

Educational use only.
